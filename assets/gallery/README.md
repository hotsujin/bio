# 현장 갤러리 사진 넣는 법

이 폴더에 강의·워크샵 현장 사진을 넣기만 하면 페이지에 자동으로 나타납니다 (코드 수정 불필요).

- 파일 이름: `photo-01.jpg`, `photo-02.jpg` … `photo-24.jpg` (번호 순서대로 표시, 최대 24장)
- 형식: jpg / jpeg / png / webp 모두 가능
- 세로 사진은 자동으로 세로 칸, 넓은 가로 사진은 자동으로 2칸을 차지합니다
- 한 장도 없으면 갤러리 섹션 자체가 페이지에서 숨겨집니다
- 넣은 뒤 `git add -A && git commit -m "갤러리 사진 추가" && git push` (Claude에게 "갤러리 사진 올려줘"라고 해도 됨)

⚠️ 공개 페이지입니다 — 수강생 얼굴 등 초상권 주의, 계약상 비공개 현장 사진 금지.
